````md
# M2.3 – Simulation Integration (L0)
## Architecture Clarification (Startup)

Status: M2.2 completed  
Goal: Define architecture for Simulation Integration into AstronoData  

---

# 1. Objective

Integrate Astronometria simulation results into the AstronoSphere pipeline.

```text
Experiments → Simulation → AstronoData/04_Simulations
````

Key requirement:

```text
Simulation results must be directly comparable to GroundTruth datasets
```

# 2. Core Questions (to be resolved)

Should Simulation datasets use the exact same structure as GroundTruth?

```text
DatasetHeader
Data[]
Measurement (L0 / VEC)
ExperimentRef
```

Decision options:

* A) identical structure (preferred for comparability)
* B) similar but separate schema

---

How do we distinguish Simulation from GroundTruth?

```text

- EPH-ASTRONOMETRIA-VEC-L0   ← candidate
```

Questions:

* Is "Provider = Astronometria" sufficient?
* Do we need additional metadata fields?
